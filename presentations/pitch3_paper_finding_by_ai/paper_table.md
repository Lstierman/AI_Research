# Paper table — 44 studies, key numbers and contribution

> **How to use:** one row per paper. Read the contribution columns first
> (`+3` strongest support … `−3` strongest opposition, `±0` mixed, `~n` indirect,
> `—` no direction), then the key numbers. Full screening notes:
> `../h1_evidence_coding.md` and the other two coding files at the repository root (Chinese). Machine-readable: `coding.csv`.
> **Codes:** +3/+2/+1 = support, strength S/M/W · −3/−2/−1 = oppose · ±0 = mixed
> within the paper · ~3/~2/~1 = indirect (target DV, no IV) · — = excluded,
> auxiliary, or no target DV.
> Numbers are as reported in the paper (or as explicitly marked in the coding
> files). “Not extracted” means the paper did not report it in a usable form.

## Contribution summary

| Hypothesis | Support n / weight | Oppose n / weight | Mixed n / weight | Indirect n / weight | Net |
|---|---|---|---|---|---|
| **H1** | 4 / 7 | 0 / 0 | 4 / 10 | 0 / 0 | **+7** |

| **H3** | 0 / 0 | 0 / 0 | 0 / 0 | 24 / 42 | **0** |

- Net = support weight − oppose weight. It ranks how much directed evidence a
  hypothesis has; it is **not an effect size** and cannot be compared across
  hypotheses.
- H1's support mass (7) is smaller than its mixed mass (10): the one
  three-channel study is mixed.
- H3's 24 indirect papers = 20 relevant + 4 auxiliary (`bmc`, `nagged`,
  `verification`, `t2_10`); the 20 in the main count are relevant only.
